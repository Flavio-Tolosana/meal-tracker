# Meal Tracker

Aplicación web para registrar tus comidas diarias. Mobile-first, funciona como PWA.

**Tech stack**: React 19, TypeScript, Vite, IndexedDB (idb)

## Desarrollo

```bash
npm install
npm run dev
```

## Comandos

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Desarrollo local |
| `npm run build` | Build de producción |
| `npm run lint` | Linting con ESLint |
| `npm test` | Tests con Vitest |
| `npm run deploy` | Build + deploy a GitHub Pages |

## Deploy

```bash
npm run deploy
```

Compila el proyecto y sube el resultado a la rama `gh-pages` usando `gh-pages`.
